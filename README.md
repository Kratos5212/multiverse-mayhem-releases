# Multiverse Mayhem: downloads and updates

An unofficial, free, non-commercial Rick and Morty fan game. Rick and Morty belongs to its creators and Adult Swim; this game is not affiliated with them.

## Download

* **Android:** [MultiverseMayhem.apk](android/MultiverseMayhem.apk). Open it on your phone to install, allowing installs from unknown sources if asked.
* **Windows:** [MultiverseMayhem.exe](windows/MultiverseMayhem.exe). Just run it. If SmartScreen warns about an unknown publisher, choose **More info → Run anyway**.

Both check this repository every time they open and update themselves automatically.

## What's in here

* `latest.json`: the newest version numbers, and every game file with its SHA-256.
* `game/<build>/`: the game files of each recent build.
* `android/` and `windows/`: the newest app and launcher.

This repository is written by `scripts/release.js` in the game's source repository. Don't edit it by hand.
